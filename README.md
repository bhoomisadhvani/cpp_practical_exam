This repository contains basic C++ programs demonstrating core Object-Oriented Programming (OOP) concepts.
Concepts Covered

Classes and Objects

Constructors

Encapsulation

Inheritance

Polymorphism

Abstract Classes

Virtual Functions

Programs Included
Book Management System – Store and display book details using objects and arrays.
Person Class Program – Demonstrates encapsulation with getters, setters, and constructors.
Animal Inheritance Program – Shows inheritance using Dog and Cat classes.
Runtime Polymorphism Program – Uses virtual functions and function overriding.
Shape Abstract Class Program – Demonstrates abstraction with pure virtual functions.

Technologies
Language: C++
Compiler: g++

Compile and Run
g++ filename.cpp -o output./output
Purpose
These programs are designed for beginners to understand and practice fundamental OOP concepts in C++.
